Dokuwu

Twelve PDF and image tools in one app. Offline, free and open source.

Merge, split, organize, compress, convert, edit and protect your documents on your own PC. Your files are never uploaded.

Windows Free Open Source (AGPL) Offline
Get it from the Microsoft Store Download the installer View on GitHub

Features

📎

Merge PDF

Combine several PDFs or a whole folder into one

✂️

Split PDF

Take out pages or ranges as a new document

🗂️

Organize PDF

Reorder, rotate, mirror, delete and insert pages visually

🖼️

PDF & Image

PDF pages to PNG, JPEG or WEBP, and images to one PDF

📝

PDF to Word

Turn a PDF into an editable Word document

🔄

WEBP to PNG/JPG

Convert WEBP images in bulk

✏️

Canvas PDF

Add text, pictures, shapes, drawings and highlights

🔧

Edit Content

Correct existing PDF text, verified before it is saved (beta)

🗜️

Compress PDF

Shrink a PDF while keeping it readable

📷

Compress Photos

Make JPEG and PNG photos smaller, many at once

🔒

Protect PDF

Add or remove a password and set permissions

🔲

QR & Barcode

QR codes and Code128, EAN-13, EAN-8, Code39 barcodes

Installation

  1. Easiest: get Dokuwu from the Microsoft Store
  2. Or download the .exe installer from the releases page and run it (no admin rights needed)
  3. If Windows SmartScreen appears, click "More info" then "Run anyway"
  4. Launch Dokuwu from your Start Menu
