# Dokuwu 2.0.0 — Release Notes

**Release type:** major. The first release built entirely on the native Rust core, with the new
brand, and free software under the GNU AGPL v3 or later. The full list is in
[`CHANGELOG.md`](CHANGELOG.md).

## Highlights
- **Native from end to end.** Every tool runs on the Rust core: no background helper program, no local server, a lighter start and much less memory.
- **New look.** A new logo and icon set, a tidier layout, and one clear green "Your file is in Downloads!" message after every tool.
- **Free software.** Dokuwu is under the GNU AGPL v3 or later. Settings > About shows the license and a new Licenses page lists everything Dokuwu is built from.
- **Microsoft Store ready.** The package scripts and the listing text are in `packaging/msix/`.
- New since 1.8.0, the version now in the Store: PDF to Word, Compress Photos, WEBP to PNG/JPG, pictures in Canvas PDF, and an Edit Content that handles many more documents.
